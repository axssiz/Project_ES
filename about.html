О проекте

Итоговый проект производственной практики «Проектирование и создание веб-сайта».

Цель

Заменить бумажный журнал записи небольшой студии красоты простым веб-приложением: администратор быстро создаёт запись, видит список на любой день, может изменить или отменить запись, а система не даёт записать двух клиентов к одному мастеру на пересекающееся время.

Функции

  • создание записи с проверкой обязательных полей;
  • просмотр списка с поиском и фильтрами по статусу и дате;
  • редактирование записи и смена статуса;
  • отмена записи и удаление с подтверждением;
  • проверка занятости времени с учётом длительности услуги;
  • сохранение данных в localStorage.

Команда

Фамилия И. О. (1)аналитик: анализ, ТЗ, журнал изменений, тестирование
Фамилия И. О. (2)проектировщик: диаграммы, модель данных, макеты
Фамилия И. О. (3)разработчик: HTML, CSS, JavaScript, localStorage

Технологии

HTML5, CSS3, JavaScript (без фреймворков), Web Storage API (localStorage).

Безопасность и ограничения

  • пароли и регистрация не используются;
  • в демонстрации применяются только вымышленные имена и телефоны;
  • пустую запись сохранить нельзя, поля проверяются по формату;
  • введённый текст выводится как текст, а не как HTML-код;
  • удаление и отмена требуют подтверждения;
  • localStorage — учебное хранилище: данные видны только в этом браузере и не защищены шифрованием.

Данные

Записи хранятся в localStorage под ключом lavanda.bookings в виде массива объектов JSON. Сейчас в хранилище: 0.

Версия 1.2. Изменения по журналу: проверка занятости времени с учётом длительности услуги (1.1); отмена записи меняет статус на «Отменена» вместо удаления (1.2).
