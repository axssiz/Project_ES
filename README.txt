ЗАПИСЬ НА УСЛУГИ — веб-приложение для студии красоты «Лаванда»
Итоговый проект производственной практики «Проектирование и создание веб-сайта»
Группа ПО2401, 2026

ТЕМА
  Запись на услуги (упрощённая): список записей, создание, изменение и отмена записи.

СОСТАВ КОМАНДЫ
  Фамилия И. О. (У1) — аналитик, тестировщик: анализ, ТЗ, журнал изменений, тесты
  Фамилия И. О. (У2) — проектировщик: диаграммы, модель данных, макеты, отчёт, презентация
  Фамилия И. О. (У3) — разработчик: HTML, CSS, JavaScript, localStorage

КАК ОТКРЫТЬ САЙТ
  1. Распаковать архив в любую папку.
  2. Открыть файл index.html двойным щелчком (Google Chrome, Microsoft Edge или Mozilla Firefox).
     Сервер, установка программ и интернет не нужны.
  3. Перейти в раздел «Записи». Если журнал пуст, можно нажать
     «Добавить демонстрационные записи» — они появятся в ленте дня на завтра.
  Данные хранятся в localStorage браузера (ключ lavanda.bookings): в другом браузере
  или в режиме инкогнито журнал будет пустым.

РАЗДЕЛЫ
  index.html     — «Главная»: календарь, сводка дня, лента дня (расписание мастеров), прайс-лист
  bookings.html  — «Записи»: лента дня, создание, просмотр, изменение, отмена и удаление записей
  about.html     — «О проекте»: цель, команда, технологии, безопасность, очистка данных

ФУНКЦИИ
  - лента дня: расписание по мастерам с 09:00 до 21:00, переход по дням, линия текущего времени;
    щелчок по свободному времени подставляет услугу, дату и время в форму, щелчок по записи открывает её;
  - отрывной календарь в шапке: при переходе на следующий день листок отрывается;
  - прайс-лист услуг с ценами в тенге (₸);
  - создание записи: имя клиента (русские, казахские и латинские буквы), телефон, услуга, дата, время, комментарий;
  - журнал записей, сгруппированный по дням, с поиском (имя, телефон) и фильтрами (статус, дата);
  - редактирование записи и смена статуса;
  - отметка «Выполнена», отмена записи (статус «Отменена») и удаление — с подтверждением;
  - проверка полей: обязательные поля, формат имени и телефона, дата не в прошлом,
    время в пределах 09:00–21:00 с учётом длительности услуги;
  - проверка занятости: нельзя записать двух клиентов на одну услугу на пересекающееся время;
  - сохранение данных после перезагрузки страницы (localStorage);
  - введённый текст выводится как текст, а не как HTML;
  - при повреждённых данных — предупреждение и резервная копия (lavanda.bookings.backup).

ДЕМОНСТРАЦИЯ НА ЗАЩИТЕ
  щелчок по свободному времени в ленте и добавить запись -> изменить -> отменить / удалить
  -> обновить страницу (F5)

СТРУКТУРА
  index.html, bookings.html, about.html, style.css, script.js, README.txt
  docs/report.docx      — итоговый отчёт
  docs/diagrams/        — IDEF0, Use Case, Class, модель данных, план Waterfall, DevOps, Kanban
                          (PNG; исходники в docs/diagrams/src)
  docs/mockups/         — макеты трёх экранов (исходник в docs/mockups/src)
  docs/screenshots/     — скриншоты сайта

ТЕХНОЛОГИИ
  HTML5, CSS3, JavaScript без фреймворков, Web Storage API (localStorage).
  Шрифты Sitka и Bahnschrift встроены в Windows: сайт выглядит одинаково и без интернета.
  Анимации отключаются, если в системе включено «уменьшение движения».

ВАЖНО
  localStorage — учебное хранилище, а не защищённая база данных.
  Используйте только вымышленные имена и телефоны.
